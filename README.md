# ZE Store

> Clean, lightweight Android APK store for browsing and downloading apps directly from GitHub Releases.

🌐 **Live Website:** [https://zyad256.github.io/ZE-Store/](https://zyad256.github.io/ZE-Store/)

---

## 🚀 Features

- 📱 **Clean Play-Store Style Interface**: Beautiful cards, detail view, and screenshot gallery.
- ⚡ **Direct GitHub Releases Integration**: Download links, release notes, and version tracking.
- 🔍 **Screenshot Lightbox**: Fullscreen preview of app screenshots.
- 📦 **Automated Deployment**: Automatically builds and deploys to GitHub Pages upon pushing to `main`.

---

## 🛠️ Local Development

### Prerequisites

- Node.js (v20+ recommended)
- npm

### Setup & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Zyad256/ZE-Store.git
   cd ZE-Store
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
